# Simple mode

New installs open in Simple mode: a status line, one big **Connect** button,
and a settings button in the top-right corner. Nothing to choose.

<img class="screenshot" src="/screenshots/simple.png" alt="Simple mode while connected: Protected, the country and time, Disconnect and Try another server">

## Connecting

- **Connect** finds the fastest server and keeps the connection working. It
  checks that pages really load, and moves to another server by itself if one
  stops.
- A line running around the button's border shows how far the connection has
  got, and the dot beside the status pulses while it works.
- **Try another server** appears once you are connected. Press it if a site
  will not load.
- **Disconnect** turns protection off.

The server list refreshes by itself every 12 hours while you are connected.

## When the trial ends

One screen says so, with a **Get access** button. Use an activation code or
subscribe with USDT — see [Access and payment](/docs/faq#access-and-payment).

## Switching view

- From Simple mode: tap the settings button (top right) →
  **Switch to professional view**.
- From the professional view: **Settings → Look → View → Simple**.

Updating from a version older than 3.5 keeps the professional view.
