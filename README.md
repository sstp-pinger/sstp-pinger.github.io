# sstp-pinger.github.io

The website and documentation for [SSTP Shield](https://sstp-pinger.github.io),
built with [VitePress](https://vitepress.dev). Pushing to `main` deploys it to
GitHub Pages.

```bash
npm install
npm run dev     # local preview with live reload
npm run build   # output in .vitepress/dist
```

Pages are Markdown: guides in `docs/guides/`, the changelog in
`changelogs.md`, the download page in `download.md`. Add a new page to the
sidebar in `.vitepress/config.mts`.
